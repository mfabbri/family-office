# Piano operativo - V4.3b Interactive JSON input wizard

## Classificazione

- Classe router: T2, micro-incremento roadmap delimitato.
- Roadmap attiva: `docs/roadmap/roadmap-v4-wealth-planning.md`.
- Incremento selezionato: V4.3b, primo `planned` dopo V4.3a `done`.
- Dipendenze: V4.3a `CLI and JSON input guides` completato.

## Obiettivo osservabile

Ridurre la compilazione manuale dei principali input JSON V4 con wizard CLI deterministici. L'utente deve poter generare draft privati validabili nel workspace rispondendo a domande leggibili, con overwrite esplicito e valori incerti tracciati come `data_gaps`.

## Ambito implementativo

- Aggiungere `fo planning goals wizard` per generare `planning-goals/v1`.
- Aggiungere `fo planning liquidity wizard` per generare `liquidity-plan-input/v1`.
- Aggiungere `fo planning decumulation wizard` per generare `decumulation-policy-set/v1`.
- Validare subito il JSON generato a livello di contratto input, senza richiedere snapshot esterni.
- Scrivere solo su path espliciti o default del workspace; rifiutare overwrite salvo `--overwrite`.
- Aggiornare help CLI e documentazione minima dei comandi.
- Aggiungere test con stdin/stdout simulati per successo, overwrite sicuro e validazione del JSON prodotto.

## Criteri di completamento

- I tre input principali possono essere creati da CLI senza aprire manualmente un file prima della revisione finale.
- Il wizard non usa LLM e non deduce importi, aliquote, rendimenti, diritti pensionistici o raccomandazioni.
- I JSON prodotti passano la validazione input pertinente.
- Dati reali e draft restano sotto `family-office-workspace/` o nel path esplicito scelto dall'utente.
- Test mirati e regression pertinente verdi.

## Test pertinenti

- Test unitari CLI con risposte simulate per goals, liquidity e decumulation.
- Test overwrite sicuro su almeno un wizard.
- Regression `tests.unit.test_validate`.

## Esclusioni

- Nessun parser, import automatico da documenti reali o generatore AI.
- Nessun calcolo fiscale, previdenziale, finanziario, FX, scoring o raccomandazione.
- Nessuna modifica a rules o knowledge.
