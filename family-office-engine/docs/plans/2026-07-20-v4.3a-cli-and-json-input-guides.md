# Piano operativo - V4.3a CLI and JSON input guides

## Classificazione

- Classe router: T2, micro-incremento roadmap delimitato.
- Roadmap attiva: `docs/roadmap/roadmap-v4-wealth-planning.md`.
- Incremento selezionato: V4.3a, primo `planned` dopo V4.3 `done`.
- Dipendenze: V4.3 `decumulation-strategy/v1` completato.

## Obiettivo osservabile

Ridurre la compilazione manuale fragile degli input JSON CLI con guide operative, esempi sintetici e una mappa generale dei comandi. L'utente deve capire quale comando usare, quali file privati preparare nel workspace e quali esempi sintetici eseguire senza leggere il codice.

## Ambito implementativo

- Guida generale CLI per ordine d'uso e capability disponibili.
- Guida unica agli input JSON compilabili con campi, default workspace, esempi sintetici e limiti.
- Guida campo-per-campo per `decumulation-policy-set/v1`, mancante dopo V4.3.
- Draft sintetico privato per `planning/decumulation-policy-set.draft.json`.
- Collegamenti minimi in `docs/cli.md`.
- Test documentale che verifica la presenza delle guide per gli input JSON attivi.
- Aggiornamento minimo di `current-next-increment.md` e roadmap V4.

## Criteri di completamento

- Ogni input JSON compilabile da CLI ha almeno una guida leggibile e un esempio sintetico o draft/template.
- La guida generale spiega le capability CLI e l'ordine d'uso senza richiedere lettura del codice.
- I documenti ribadiscono che i dati reali restano sotto `family-office-workspace/`.
- Test mirati e regression pertinente verdi.

## Test pertinenti

- Test unitario documentale su guide e riferimenti agli esempi JSON attivi.
- Smoke CLI esistenti per planning goals, liquidity e decumulation.
- Regression unitaria pertinente con `tests.unit.test_validate`.

## Esclusioni

- Nessun nuovo calcolo, parser, rule pack o interpretazione normativa.
- Nessun wizard interattivo e nessuna migrazione di dati reali.
- Nessuna modifica a knowledge o rules.
