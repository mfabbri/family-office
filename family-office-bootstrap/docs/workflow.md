# Workflow

## Agent flow

```text
task
  → classify T0–T5
  → context budget
  → model/effort routing
  → targeted playbook
  → deterministic implementation/tools
  → proportional tests
  → concise completion report
```

## Data and calculation flow

1. Depositare documenti reali nel workspace.
2. Inventariare con provenance.
3. Importare e normalizzare documenti classificati.
4. Aggiornare household graph, ownership, disponibilità e timeline.
5. Applicare rule pack versionati.
6. Generare cashflow, simulazioni e stress test.
7. Produrre evidence bundle e decision dossier.
8. Registrare lineage, data gaps e decisioni.

## Development flow

```text
roadmap-index + current increment
  → one active roadmap
  → contract/fixture
  → implementation
  → targeted tests
  → regression gate
  → minimal documentation update
```

## Normative flow

```text
authoritative source → knowledge → rules → tests → engine → regression
```

## AI flow

```text
question → intent → inspectable plan → deterministic tools → evidence → cited explanation
```

L'LLM non modifica facts approvati e non esegue direttamente calcoli fiscali, previdenziali o finanziari.
