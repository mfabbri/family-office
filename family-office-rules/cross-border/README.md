# Cross-Border

Regole tecniche per coordinamento cross-border, senza dati personali.

- `eu-pension-coordination-it-es.json`: metodo `eu-pension-coordination-rule-pack/v1` per coordinamento pensioni pubbliche Italia-Spagna. Codifica separazione dei diritti nazionali, totalizzazione ai soli fini del diritto e pro-rata solo quando gli input sono sufficienti.
