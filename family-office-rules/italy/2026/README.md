# Italy 2026

Regole fiscali italiane per anno 2026.

- `irpef-national.json`: IRPEF nazionale lorda su imponibile gia' determinato. Non include detrazioni, addizionali, crediti o calcolo dichiarativo completo.
- `pension-contribution-deduction.json`: limiti deducibilita' contributi a previdenza complementare per `pension-contribution-options/v1`. Non calcola IRPEF completa, rendimenti, matching contrattuale o consulenza.
